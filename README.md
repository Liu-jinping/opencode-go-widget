# opencode go 额度悬浮小组件

一个钉在桌面上的小窗，实时显示 opencode go 订阅的剩余额度：三行（Rolling / Weekly / Monthly），
每行是「标题 + 绿色百分比徽标 + 右侧 Resets in」，下面是灰底绿条进度条，底部一行小字状态栏。

常驻**系统托盘**（不占任务栏），托盘悬停就能看到速览；拖到屏幕左右边缘会自动收缩成一条
约 36px 宽的**圆环条**，只在边缘显示 5 小时剩余额度，悬停再滑出完整面板。

纯 Python 标准库 `tkinter` + `ctypes` 实现，**不装任何第三方依赖**，兼容 Python 3.10+（含 3.14）。

## 一、启动

**方式 1（推荐）**：双击 `opencode-widget.bat`

**方式 2**：直接双击 `widget.pyw`（系统已把 `.pyw` 关联到 Python 启动器）

**方式 3**：命令行

```bat
pythonw D:\test\opencode-go-widget\widget.pyw
```

> 需要机器上装有 Python 3.10 或更高版本。脚本会按 `PATH 里的 pythonw` → `pyw.exe` → `文件关联` 的顺序自动选择启动方式。

启动后小窗默认出现在**屏幕右上角**，置顶显示。首次打开会在 1 秒内完成第一次拉取。

## 二、开机自启

1. 按 `Win + R`，输入 `shell:startup` 回车，打开「启动」文件夹；
2. 在该文件夹里右键 → 新建 → 快捷方式；
3. 位置填：`D:\test\opencode-go-widget\opencode-widget.bat`；
4. 命名为 `opencode-go 额度小组件`，完成。

下次登录 Windows 就会自动启动。取消自启：把该快捷方式从启动文件夹删掉即可。

## 三、换 token（三种方式，按优先级从高到低）

| 优先级 | 方式 | 说明 |
| --- | --- | --- |
| 1 | 环境变量 `OPENCODE_TOKEN` | 临时生效，只影响当前启动的进程 |
| 2 | 同目录 `config.json` 的 `token` 字段 | 长期生效，复制 `config.json.example` 改名 `config.json` |
| 3 | opencode 登录信息 `auth.json` | 默认自动读取，无需任何配置 |

**默认情况（第 3 种）不需要做任何事**：程序会读取

```
C:\Users\<用户名>\.local\share\opencode\auth.json
```

里顶层 key `"opencode-go"` 下的 `key` 字段。

如果要自己指定 token：

1. 复制 `config.json.example` 为同目录的 `config.json`；
2. 把 `token` 填成你的 key：

```json
{
  "token": "sk-xxxxxxxx",
  "interval_sec": 60,
  "opacity": 1.0,
  "width": 400,
  "edge_dock": true
}
```

3. 保存后在小窗上**单击一下**（或右键 → 立即刷新）即可生效，不用重启。

> `opacity` 是透明度（0.5~1.0），`width` 是窗口宽度（280~640），`edge_dock` 是贴边自动收缩开关（见第九节）；不填就用默认值。

> `config.json` 里是真实密钥，请不要提交到代码仓库或发给别人。

---

## 四、改刷新间隔

`config.json` 里的 `interval_sec`，单位秒，默认 `60`，最小 `10`：

```json
{ "token": "", "interval_sec": 120 }
```

改完单击小窗刷新一次即可生效。

## 五、界面操作

| 操作 | 效果 |
| --- | --- |
| 左键按住拖动 | 移动小窗位置；拖到屏幕左右边缘（8px 内松手）自动贴边收缩，见第九节 |
| 左键单击（不拖动） | 立即刷新数据 |
| 右侧 8px 抓柄按住左右拖 | 改窗口宽度（280~640，见第七节） |
| 双击右侧抓柄 | 恢复默认宽度 400 |
| 右键单击 | 弹出菜单：立即刷新 / 取消置顶（恢复置顶）/ 隐藏窗口 / 贴边自动收缩 / 透明度 / 退出 |

**每一行显示什么**

- 标题：`Rolling usage` / `Weekly usage` / `Monthly usage`
- 绿色徽标：`8% used`（已用百分比）
- 右侧灰字：`Resets in 2h 27m`，会自动换算成 `Xd Xh` / `Xh Xm` / `Xm`
- 进度条：灰底 `#e2e2e2`，绿色填充 `#2e9e5b`，长度 = 已用百分比
- 底部状态栏：左边圆点 + 最后更新时间，右边操作提示

## 六、透明度调节

右键 → **透明度**，展开 `100% / 90% / 80% / 70% / 60% / 50%` 六档，当前档前面有勾号。
选中后小窗立刻变透明，同时写进 `config.json` 的 `opacity` 字段，下次启动沿用。

- 取值范围 `0.5 ~ 1.0`（越界自动按 0.5 / 1.0 处理），默认 `1.0`（完全不透明）
- 手动改也行：`{ "opacity": 0.8 }`
- 圆角镂空不受影响，调到 50% 依然是圆角白卡片，不会露出方角
- 菜单本身始终不透明，方便看清选项

## 七、宽度调节

窗口**右侧边缘约 8px** 是隐形抓柄，鼠标移上去会变成左右双向箭头，按住左键左右拖即可改宽度：

- 可调范围 `280 ~ 640`（默认 `400`，高分屏上按缩放比例换算成实际像素）
- 拖动时高度不变，进度条跟着拉伸，绿色徽标和右侧 Resets in 自动重排、不会叠在一起
- **双击抓柄**恢复默认宽度 400
- 松手后写进 `config.json` 的 `width` 字段，下次启动按上次的宽度打开
- 抓柄拖到屏幕边缘时窗口会自动往左让位，保证抓柄始终留在屏幕内；如果贴到边缘（8px 内松手）
  且开着「贴边自动收缩」，就会收缩成圆环条（见第九节），此时没有抓柄，把面板拖离边缘即可恢复正常宽度

不想用鼠标也可以直接改配置：`{ "width": 520 }`

## 八、系统托盘图标与显示 / 隐藏

程序启动后常驻**系统托盘（通知区域）**，不占用任务栏。托盘图标是用标准库 `ctypes` 调
`Shell_NotifyIcon` 做出来的**真正托盘图标**，图标直接用系统的默认图标 `LoadIcon(IDI_APPLICATION)`，
**不新增 .ico 文件、不装任何第三方依赖**，Win10 / Win11 均有效：

| 操作 | 效果 |
| --- | --- |
| 启动 | 托盘（含 Win11 的「^」溢出区）立刻有图标，图标常驻不消失 |
| 左键单击 / 双击 | 切换小窗显示 / 隐藏（单击与双击都能切换，双击不会切换两次） |
| 右键单击 | 弹出 Windows 原生菜单：显示窗口 / 隐藏窗口 · 立即刷新 · 退出 |
| 隐藏窗口（或菜单里选隐藏） | 小窗 withdraw 收起，只剩托盘图标；后台 60 秒轮询照常跑，数据不停 |
| 单击托盘图标再展开 | 窗口出现在原位置（收缩态则还原成圆环条），数据仍是最新一次结果 |

小窗本体是无边框窗口，永远不会出现在任务栏和 Alt+Tab 里——托盘是唯一的常驻入口。

**托盘悬停速览（tooltip）**

每次轮询成功后，把最新结果写进托盘 tooltip（`szTip`，64 字以内），把鼠标放到托盘图标上就能看到：

```
5h已用8%·2h25m后重置 | 周8% | 月9%
```

- `5h` 是 Rolling（5 小时滚动额度），`周` / `月` 是 Weekly / Monthly 已用百分比
- 请求失败时 tooltip 直接显示错误简称，例如 `401 key 无效`、`网络超时`
- 更新 tooltip 走的是 `NIM_MODIFY`，**只改文字、不删除重建图标**，所以不会闪烁

## 九、贴边自动收缩（圆环条）

把小窗拖到**屏幕左边缘或右边缘**（距边缘 8px 内松手），它会自动吸附并收缩成一条
约 **36px 宽的圆角圆环条**，只在边缘留一个小小的进度指示：

- 圆环显示 **Rolling（5 小时）的剩余额度**（剩余 = 100 − 已用），环中心文字就是剩余百分比，例如 `92%`
- **鼠标移上去**（或拖动收缩条）面板会从边缘滑出，变回完整的三行面板，贴边锚点不变
- **鼠标离开面板 800ms 后**自动收回边缘；刚吸附的瞬间不会自己弹开
- 把面板**拖离边缘**即可恢复正常宽度，窗口中心保持不动（刚好停在鼠标下方）
- 收缩态下透明度、置顶、60 秒轮询全部照常；**请求失败时圆环变红**，剩余额度用完（0%）也是红色
- 圆环条上同样可以右键弹菜单、左键单击刷新

右键 → **贴边自动收缩** 可以开关这个功能（当前状态前面有勾号），选择后写进 `config.json`
的 `edge_dock` 字段（默认 `true`），下次启动沿用：

```json
{ "edge_dock": false }
```

关闭后再把窗口拖到边缘就不会吸附了；如果当前已经吸附，会立刻恢复正常宽度。

## 十、数据状态怎么看

| 显示 | 含义 | 处理办法 |
| --- | --- | --- |
| 绿色圆点 +「更新于 HH:MM:SS」 | 拉取成功 | 无需处理 |
| 红色圆点 +「更新失败 …」，对应行变红 | 该次请求失败 | 按行内原因处理，见下 |
| 行内显示 `401 key 无效` | token 不对或已失效 | 换 token（见第三节） |
| 行内显示 `403 未订阅` | 该账号没有 opencode go 订阅 | 确认订阅状态 |
| 行内显示 `网络失败` / `网络超时` | 断网、代理或接口不可达 | 检查网络后单击刷新 |
| 行内显示 `无数据` / `数据异常` | 接口返回结构变了 | 看 `widget.log` |
| 徽标显示 `100% used` 且该行是限流状态 | 接口返回 `rate-limited`，按 100% 展示 | 等到 Resets 时间后自动恢复 |

请求在后台线程执行，界面不会卡；每行独立渲染，哪行出错哪行变红，不影响其他行。

## 十一、常见问题

**1. 双击 bat 没反应？**
先在命令行里手动跑一次看报错：

```bat
cd /d D:\test\opencode-go-widget
C:\path\to\pythonw.exe widget.pyw
```

常见原因是没装 Python，或 `.pyw` 关联被改掉。

**2. 窗口不见了？**
先看**系统托盘**（任务栏右下角，Win11 可能在「^」溢出区里）：单击托盘图标就能展开窗口。
如果只是被别的窗口挡住，右键 → 恢复置顶；实在找不到就到任务管理器结束 `pythonw.exe` 再启动。

**3. 托盘图标不见了？**
程序退出时会主动删除托盘图标；如果进程还在（任务管理器里有 `pythonw.exe`）而图标没了，
多半是图标被系统折叠进溢出区，把托盘图标拖出来即可。没有托盘图标时说明程序已经退出，重新启动即可。

**4. 想看报错？**
程序把意外异常写在同目录 `widget.log`。
也可以先设 `OPENCODE_WIDGET_DEBUG=1` 再启动，会额外记录按下/拖动/松开、抓柄光标切换、
贴边吸附 / 展开 / 收回等交互日志，用来排查拖动、点击、改宽、贴边问题。

**5. 高分屏上字很小 / 发虚？**
程序启动时会开启 Windows DPI 感知并按缩放比例布局，125% / 150% / 200% 都能正常显示，无需手动调；
宽度、透明度、圆环条也都会按同一比例换算。

**6. 不想要它了？**
右键 → 退出（或托盘菜单 → 退出），托盘图标会一并消失；再删掉启动文件夹里的快捷方式；
最后删除整个 `opencode-go-widget` 文件夹即可，不会写注册表、不留后台服务。
